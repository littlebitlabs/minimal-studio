# Security

Please report a security problem privately, not in a public issue: use **Security > Report a vulnerability** on this repository.

Never put a server key, an access token, a password, a license secret, an encryption key or a backup archive in an issue, a pull request or a log you paste. Redact them first. If you posted one by mistake, treat it as leaked: rotate it.

This repository holds a brief that tells an AI agent how to use Minimal Studio, the Book of Minimal Studio, and the signed Minimal Studio downloads. It holds no Studio source code and no secret, and the brief tells the agent never to ask for one in a chat. Vulnerabilities in Minimal Studio or in Minimal itself go through the private report above, or to Littlebit Labs directly.
